# Icon 图标

移动端图标组件，基于 Taro H5 渲染。演练场仅展示 H5 预览，小程序表现请以 `mobile-lab` 为准。

## 基础用法

在文档页可以纵向查看所有示例；需要临时调整 props 时，点击左侧某个示例或示例卡片中的调试入口进入单示例演练模式。

## 设计说明

- `name` 指定图标类型，当前支持 `search`、`close`、`check`。
- `size` 控制图标尺寸，支持数字或带单位的字符串。
- `color` 控制图标颜色，默认跟随当前文字色。
- H5 预览下使用占位汉字展示图标语义，便于在文档站快速调试布局与尺寸。

## API

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `name` | 图标名称 | `'search' \| 'close' \| 'check'` | — |
| `size` | 图标尺寸 | `number \| string` | `16` |
| `color` | 图标颜色 | `string` | `'currentColor'` |
| `class` | 自定义类名 | `string` | `''` |
